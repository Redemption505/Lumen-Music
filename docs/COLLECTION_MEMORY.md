# 收藏与记忆

v0.2.2 提供普通歌单封面与短说明、偏好版本分组、最近播放日期卡片和筛选。歌单封面与说明、日记编辑及卡片浏览不会中断当前播放或改动播放队列。最新安装与运行实测结果见 [v0.2.2 验收](V022_ACCEPTANCE.md)。

## 歌单封面与说明

展开侧栏“我的歌单”，选择普通歌单，点击页头“封面与说明”。点击“选择本地封面”选择不超过 16 MiB 的 PNG/JPEG 图片；预览保留完整比例，不裁剪。图片最长边超过 256 像素时缩至 256，较小图片不放大，再转为最多 512 KiB 的内嵌 PNG。保存后不依赖原图片路径，删除或移动原图片不会丢失封面。

“简短说明”最多 280 个 Unicode 字，支持换行。点击“保存”同时保存当前封面与说明；“取消”丢弃本次调整。读取图片失败保留之前的选择；保存失败保留窗口中的草稿和错误提示，可再次保存。保存期间禁用重复提交。

点击“使用曲目拼图”并保存可清除自选封面，恢复歌单顺序中前四个不同的实际曲目封面组合；只有一张时完整展示，无封面或图片未加载时显示音乐占位。清空说明并保存可移除说明。自选封面和拼图均保留完整图片比例。

这些设置只适用于普通歌单。说明与内嵌封面保存在现有 `library.json`，随 ZIP 数据备份导出、预检和恢复；旧 v1 曲库和备份没有新字段时使用空说明与曲目拼图。接口规则见[本机接口契约](API.md)。

## 歌曲版本

在歌曲行“... → 歌曲版本”或沉浸页“版本”进入整理窗口。手动设定的偏好位于“我常听的版本（偏好）”，其他版本保留在下方；卡片展示保存的版本说明、演唱者、真实资源标题及来源。现场、翻唱等说明使用个人标注，实际片段资源另有“片段”标记。明确播放某个版本仍使用所选资源。整理、替换及撤销规则见[歌曲版本管理](SONG_VERSIONS.md)。

## 最近播放

侧栏“最近播放”的备注和歌词页按真实日期展示卡片，可筛选具体日期或全部日期；缺失日期保持未知。备注展示完整正文、资源和创建/更新时间；歌词展示收藏文本、日期及“从这句播放”的回听位置。

备注保存失败后，刷新或切换曲目仍保留本次运行中的对应草稿。歌词保存失败可在待保存卡片点击“重试保存”，继续使用原曲目、原文和原位置。草稿尚未入库，应用关闭后不恢复。日期语义、回顾统计及导出方法见[最近播放](MUSIC_DIARY.md)。

歌词、日期与封面的纪念卡图片导出仍按第四阶段规划排在安卓核心播放之后，v0.2.2 尚未提供。现有日记 Markdown、纯文本导出及 ZIP 备份继续可用，私人备注不进入推荐请求。
