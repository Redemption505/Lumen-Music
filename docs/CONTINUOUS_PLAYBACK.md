# 连续播放

## 下一曲准备

“设置 → 音频 → 提前准备下一曲”默认开启。正在播放或暂停时，播放器根据当前队列准备一个真实后继，不提前推进队列。随机模式保留同一个下一曲选择；手动安排优先于普通歌单和电台推荐。

插队、调整顺序、删除、切换播放方式或电台后，过时任务会取消。关闭该选项、进入 A–B 循环或片段试听也会取消准备。

优先使用已有完整缓存。VLC 未开启永久缓存时只提前检查音源，不下载整段长视频；JavaFX 或开启永久缓存时可准备一个受容量限制的完整临时文件。未播放的准备文件不写入永久缓存或听歌记录，也不会把歌曲标成失效。

VLC 的新准备文件不超过缓存容量与 256 MiB 中较小的值；JavaFX 的会话音频上限为 256 MiB。JavaFX 播放持久缓存时使用会话副本，清空持久缓存不会删除正在使用的音频，也不要求停止音乐。

准备失败不打断当前音乐，实际点播仍走正常播放与有限重试流程。下一曲尚未准备好时仍可能需要等待，网络音源不保证无缝或零等待。

## 短淡入淡出

“设置 → 音频 → 短淡入淡出”默认关闭。开启后，新曲开始及暂停恢复采用约 200 毫秒淡入，自然终点采用约 200 毫秒淡出。手动切歌直接切换再淡入，不增加淡出等待。

淡化增益与音量滑块、响度归一化分别处理，不改写用户音量或歌曲测量值；变速时按实际时间计算淡出范围。A–B 练习和片段试听不使用自然终点淡出。它不是双音轨交叉淡化，也不保证两个音源间没有间隔。

原生进度采样较粗时，音量增益独立平滑计算；歌词、收听记录和自然结束仍使用真实播放进度及引擎事件。

两项偏好在本机保存，重启后保持。具体测试与发行状态见[验证结果](VALIDATION.md)和[阶段说明](PHASE3_EXPANSION.md)。
