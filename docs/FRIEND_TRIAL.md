## 可转发说明

想请你在自己的 Windows 10/11 x64 电脑试用 Lumen Music，主要看看能否自己安装、找到功能并正常听歌。安装包自带运行环境，不需要安装 Java、Python、VLC 或开发工具，也不需要登录或配置 AI。请先按随附的本轮交付身份领取唯一候选包，应用打开后在“设置 → 版本与反馈”核对完整构建号。

先用你自己的、允许使用的本地音频做下面几件事，约 15–20 分钟；找不到入口也请记录，不用等别人现场讲解：

1. 解压完整包、运行 Setup.exe。在安装向导点“浏览…”选择一个自己可写的文件夹，记录目录选择窗口是否打开、选中路径是否正确。安装后从快捷方式首次启动，记录等待或报错。
2. 在“本地音乐”导入一个含子目录的音乐文件夹，再导入一次，看看是否出现重复。播放、暂停、切下一首并拖动进度；若音频本身有封面或歌词，看看是否显示。没有这些标签可填“不适用”，不用另找测试素材。
3. 收藏一首歌，建一个歌单；退出再打开，检查收藏和歌单是否保留，并从首页继续听。重启时应保持暂停。
4. 切换主题、进入沉浸页和迷你播放器，看看文字、歌词与操作是否清楚，声音和队列是否保持。可选：用自己可用的在线来源，尝试偏好版本或合集片段；无来源时跳过并注明。
5. 在“设置 → 数据与隐私”导出备份。在专门试用账户或已明确用于测试的资料中，先备份当前资料，再预检/确认恢复，检查收藏与歌单。已有日常资料时先只验证导出和预检，恢复留待约定的测试环境。
6. 自由听几天，特别记录耳机使用、连续收听、快速切歌或关闭时的异常。若本轮安排了旧版升级，按包的适用版本升级并确认原资料、安装目录和新构建；没有旧版就填“不适用”。最后找找卸载入口；实际卸载只在你同意的试用目标上做，核对个人资料仍保留。

反馈请带上版本/构建号、Windows 版本、显示缩放、做了什么、期望什么、实际发生什么及能否重复，填[反馈模板](FRIEND_FEEDBACK.md)。截图/录屏可选，请避开私人信息。能打开应用时可在“设置 → 版本与反馈”导出诊断 ZIP；打不开时按[使用指南的启动失败说明](WINDOWS_GUIDE.md#启动失败与反馈)记录包身份、时间与现象。

不需要发送整个个人目录、备份 ZIP、音频或完整原始日志。若之前遇到首次启动闪退，请在同一电脑重走原步骤，并记录这次结果；没有复测就保留待复测，不能由别人电脑正常启动代替。

最后也想知道：你最愿意保留哪三个功能，哪个功能没发现，在哪个场景愿意日常使用它。功能建议和故障可以分开写。
