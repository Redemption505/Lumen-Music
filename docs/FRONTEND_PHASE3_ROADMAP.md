# 第三阶段前端功能与验证状态

第三阶段前端及六项独立验收问题已完成源码和实际安装版验证，当前候选为 `lumen-0.2.2-20261024.1`。交付范围和结果见[第三阶段验收](FRONTEND_PHASE3_ACCEPTANCE.md)。以下说明现有功能，不将静态装饰描述为音频驱动动画。

## 当前功能范围

1. **首页封面与灵感入口**：继续听区域在有可用封面时显示曲目封面；无封面或图片尚未加载时显示静态音符占位。今日重逢区域可显示曲目封面缩略图。发现区域提供四个预设意图按钮，点击后填入查询并触发推荐。
2. **曲目列表**：右侧元数据采用横向排列；封面悬停显示播放或暂停入口；当前播放曲目显示标记；选中且正在播放时有独立渐变样式。
3. **音量控制**：音量图标可静音及恢复到先前音量；图标和滑轨支持滚轮按 5% 调节，并显示当前百分比提示。
4. **沉浸歌词**：提供三档字号，支持页内按钮和菜单切换；字号影响歌词行高，视口变化时按当前行高调整上下留白。
5. **快捷搜索**：结果显示类型标记和回车提示，底部显示键盘操作提示；空结果状态包含搜索建议。
6. **专注计时**：深度专注和睡眠定时控件分别放入卡片，计时数字使用更醒目的字号。

播放器使用的 music SVG 是静态音符图标路径，用作界面标识；它不随音频播放变化，也不是唱片或封面图。个人首页唱片封套在有图片时叠加曲目封面；封套图片不可用时显示 Unicode 音符占位“♫”。唱片位置和播放状态样式由界面状态控制。
