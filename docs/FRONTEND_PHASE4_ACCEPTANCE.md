# 第四阶段前端验收

本文保留 `lumen-0.2.2-20261024.2` 的历史范围；后续收藏/本地入口、唱针等已进入[前端第二阶段](FRONTEND_STAGE2_ACCEPTANCE.md)，当前身份见[候选说明](PHASE4_RELEASE_CANDIDATE.md)。

更新：2026-10-24。本轮限定交付范围的三项界面修复与回归通过，当前安装候选为 **v0.2.2 / `lumen-0.2.2-20261024.2`**。未实施设计仍列为后续任务，不将整份前端路线图标记为全量完成。

## 修复与验证

| 问题 | 最终行为与实际检查 |
| --- | --- |
| 播放全部低对比度 | 复用配对的强调色前景/悬停背景。五主题、六强调色、两尺寸、双缩放检查正常/悬停/焦点的计算色对比度，均至少 4.5；禁用另核对有效 Paint 与 0.55 透明度，不将底色对比等同于禁用合成后对比 |
| 首页悬停颜色未定义 | 普通常驻卡片和继续听使用有效颜色角色；两个不同真实节点的悬停边框检查通过，无相应 CSS 转换警告 |
| 底栏中心偏移 | 循环按钮对侧采用等宽占位，时间行两侧等宽约束。测量实际播放按钮与轨道中心，五主题、两尺寸、双缩放及短/小时级时间文字在 1px 容差内；8px 位移负例被拒绝 |

## 验收层级

- Java 325 项通过，0 失败、错误、跳过；扩展离屏双缩放通过，保留轨道越界与歌词透明度负例。
- 当前源码完整视觉与专用首页均通过 125%/150%：五主题、1280×800/860×600，播放保持、歌词三档、封面四角、菜单、焦点正负例、迷你返回均通过。
- 歌单空/非空可用状态、标题/歌手查找、无匹配/清空、全列表和队列保持、播放全部顺序及上下文通过。查找定位不会隐藏未匹配项。
- 专用首页显式滚回顶部后的首屏标题检查通过；普通滚动时的顶部裁切不作为首屏缺陷。
- 实际安装 JAR 的两档完整视觉与新增回归通过，类加载来源核对为安装目录主 JAR；不是借用源码 classes 代替。
- 真实同版本升级和原资料原生首页/本地音乐/歌单/迷你返回/正常退出通过；使用捆绑 JVM/Python/Rust，自有进程退出、端口释放。未播放个人曲目。
- 升级前保留安装及资料恢复备份；升级与运行后业务文件字节保持，正常运行日志、实例端点及偏好保存按资料核对分别记录，没有清空资料。

身份与包内 SOURCE/校验入口见[当前候选](PHASE4_RELEASE_CANDIDATE.md)，复现方法见[开发说明](DEVELOPMENT.md)。归档用 `verify-phase3-release.ps1` 核对清单、对应源码及身份；GitHub CI 以[对应提交](https://github.com/Redemption505/Lumen-Music/actions/workflows/verify.yml)独立核对。源码、安装、归档、CI和外部试用各有范围。
