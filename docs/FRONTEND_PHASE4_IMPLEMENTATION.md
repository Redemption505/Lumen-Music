# 第四阶段前端实施范围

更新：2026-10-24。本轮限定范围已完成三项界面修复并通过源码与实际安装版验收，当前候选为 `lumen-0.2.2-20261024.2`；具体结果见[第四阶段验收](FRONTEND_PHASE4_ACCEPTANCE.md)。以下是实际能力，不将未实施设计视为完成。

## 已实现

- 首页卡片间距与内边距微调；悬停使用有效主题边框。
- 歌单详情页播放全部、标题/歌手查找定位与匹配计数。播放全部从第一首开始，保留歌单顺序和上下文。
- 查找定位到第一首匹配，列表保留全部曲目；无匹配只提示，清空后隐藏计数，不替换播放队列。这不是过滤。
- 底栏播放按钮与实际进度轨道中心对齐，覆盖不同时间文字宽度。
- 沉浸页舞台渐变、当前歌词轻阴影、迷你播放器投影及设置面板间距调整。

## 本轮修复

播放全部复用配对强调色角色；首页悬停不再引用未定义颜色；底栏上、下两行均考虑实际控件宽度。永久回归已覆盖五主题/六强调色、普通与继续听两种卡片、实际中心测量和位移负例、歌单查找/播放顺序，以及显式滚到顶部的首页检查。源码与安装 JAR 的双缩放结果分别记录在验收文档中。

## 未实施 / 后置

真正列表过滤、收藏与本地音乐新播放全部入口、底栏信息去前缀、唱臂与声学暗纹、新音源/版本铭牌、侧栏歌单导引线、设置折叠状态摘要。本轮没有右键菜单对应增量，既有菜单仍可用。

真正过滤如进入后续范围，需要同时验证过滤后播放、删除、拖动与原始曲目身份的正确关联；本轮不通过改名或隐藏列表来代替该设计。

## 验证入口

从仓库根目录运行 `./desktop/mvnw.cmd -f desktop/pom.xml test`。完整环境及离屏、窗口入口见[开发与复现](DEVELOPMENT.md)，范围和剩余条件见[验收](FRONTEND_PHASE4_ACCEPTANCE.md)与[路线图](FRONTEND_PHASE4_ROADMAP.md)。单元测试、源码窗口、实际安装、CI和独立设备各自验收。
