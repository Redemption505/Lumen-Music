# 第四阶段前端路线图

## 当前范围

本轮限定为首页与现有页面微调、歌单主操作区和查找定位，以及按钮对比度、首页悬停、底栏对齐三项修复。该范围已经验收；全部设计设想仍未完成。实现与证据见[实施范围](FRONTEND_PHASE4_IMPLEMENTATION.md)和[第四阶段验收](FRONTEND_PHASE4_ACCEPTANCE.md)。

| 批次 | 已实现并验收的范围 | 后置设计 |
| --- | --- | --- |
| 首页与底栏 | 首页间距、有效悬停边框、播放按钮与实际轨道中心对齐 | 曲目信息去前缀 |
| 歌单操作 | 详情页播放全部、标题/歌手查找定位、匹配计数与可读配色；列表和队列保持 | 真正过滤；收藏/本地音乐新播放全部入口 |
| 沉浸播放 | 舞台渐变与歌词轻阴影 | 唱臂、声学暗纹、音源/版本铭牌与歌词引言设计 |
| 侧栏与设置 | 迷你投影、设置面板间距、相关回归与本轮交付 | 歌单导引线、折叠状态摘要 |

歌单查找保留全部曲目，仅滚动并选择首个匹配；不是实时过滤。后续若实现过滤，须覆盖播放、删除、拖动等操作与原曲目身份的映射，不直接复用显示索引作为原列表索引。

## 继续推进

优先沿用第四阶段主文档的稳定性与外部试用安排。后置视觉设计需另行确认范围，不为填满原路线图一次添加。新增设计继续遵守主题色、文字可读性、轨道几何、歌词字号、封面四角、播放保持和资料保护要求；当前通过不能替代后续改动的回归。

从项目根目录运行 `./desktop/mvnw.cmd -f desktop/pom.xml test`；离屏、真实窗口、实际安装与归档入口见[开发与复现](DEVELOPMENT.md)和[当前候选](PHASE4_RELEASE_CANDIDATE.md)。独立电脑、重启首启、性能预算等剩余条件保持各自状态。
