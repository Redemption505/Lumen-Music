# 前端优化交付验收

更新：2026-10-22。版本保持 v0.2.2，新构建 `lumen-0.2.2-20261022.1`。首页与全局样式改进、三处样式修复已进入实际安装版；交付身份和入口集中在[当前候选](PHASE4_RELEASE_CANDIDATE.md)。

## 改动与直接回归

- 首页调整标题、状态徽标、继续听与推荐区的层级和间距；沿用原队列、恢复与首页持久化逻辑。
- 为迷你返回按钮增加可见的键盘焦点；首页辅助/常驻按钮和侧栏文字按主题角色取色；为真实歌单操作栏设置匹配 CSS 的节点 ID。
- `FrontendStyleAssertions` 直接检查实际控件的文字对比、边框与操作栏背景，接入首页和视觉场景，驱动只进入测试构建。上一轮 11 项定向 Java 回归及两驱动的 125%/150% 场景均通过。
- 本轮实际生产 JAR 的首页两档缩放通过，确认类来自新 JAR。全视觉自动场景在五主题/两尺寸页面检查后因焦点像素断言失败，保留原记录；原生深色首页与迷你返回的 Tab 边框可见，实际返回正常。尚未证实自动失败原因，不能将原生复验写成该自动场景通过。

## 实际安装与原生操作

先备份安装及原资料，再用同版本升级安装器；退出码 0，784 个运行文件与新镜像一致，327 个个人资料文件在安装瞬间字节不变。只保留 Windows PATH，分别打开新镜像的独立资料和实际安装版的原资料，确认捆绑 JVM、Python、Rust 与端口归属。

原生操作在本轮明确安排的短时接管中完成：首页阅读/Tab 焦点，歌单与本地音乐切页，迷你窗布局、返回焦点及返回主窗口；两轮均 Alt+F4 正常关闭，launcher/窗口退出 0、全部自有进程停止、端口释放。没有播放音乐、重启系统或清空资料。资料比较显示收藏/歌单/历史/队列的字节和语义保留；偏好原键值保留，时间、端点与日志按正常生命周期写入。

镜像窗口首次观察 13539 ms、探针 ready 24477 ms；安装版原资料对应 10187/22587 ms。没有统一 UI 可操作/退出计时分布，不能据两个不同场景的单样本判断性能改善。

## 交付与未覆盖范围

完整安装包、v0.2.1 基线增量包、同字节 SOURCE 及校验和使用同一构建身份；实际归档内容另行逐项验证。源码提交至原私有仓库，CI 与原生安装是不同证据。

本轮没有重测公网来源、真实歌曲长听、独立电脑、系统重启首启及原闪退者反馈。旧三份隔离新资料计时仅属于 10 月 10 日构建。自动全视觉场景的焦点截图问题、性能预算及外部验收继续明确保留；不影响已观察到的具体原生操作结论。
