| 范围 | 当前行为与验证边界 |
| --- | --- |
| 收藏及歌单查找 | `TrackLocator` 按标题或歌手匹配，采用 `Locale.ROOT` 忽略大小写。列表增删、替换或重排时重算匹配位置并归位首项，Enter 在匹配项间循环；不隐藏未匹配曲目、不改播放队列 |

| 唱针 | 绑定播放状态；仅 PLAYING 为演奏中，加载、缓冲、暂停、结束和失败分别显示。工程状态注入只能验证映射，不能当作真实网络卡顿复现 |
