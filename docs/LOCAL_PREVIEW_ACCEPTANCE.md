实际JVM日志分别记录 `Forcing UI scaling factor: 1.25` 与 `1.5`，未修改系统显示设置。两档窗口句柄首次观测为4.61/5.73秒，探针就绪为10.35/11.96秒；后者包含服务、进程及端口核对，不是纯渲染或单独计时的UI响应。样本沿用同一资料，不能据此宣称冷启动性能改善。

首次尝试因私有探针仍检测旧进程名而漏记Preview窗口，并出现文字树与截图不一致，已停止输入并由用户正常关闭，失败证据保留。探针改为按实际EXE名称检测、显式显示测试窗口并激活新返回窗口后，双缩放复验通过；没有放宽启动/健康/退出断言。截图错配的单独根因未证实。原记录的 `firstProfile` 字段只检查 `library.json`，不可靠，不能拿它将本轮重试写成全新资料首启。

此前2GiB作为资源安排条件；用户随后明确要求直接开始，本轮按该指示执行并记录资源背景，未再以此阻断。十分钟接管已经结束，没有自动重启、后台输入或二进制发布。私有证据位于 `build/local-preview-acceptance-20261113/`，不随源码上传。

11月18日从便携 ZIP 解压到带空格和中文的新目录，校验1,917项内容与5个关键 x64 二进制。用隔离的空资料和仅系统目录的 `PATH` 启动包内 Python 服务，在线策略拒绝、本地收藏及歌单跨服务重启、备份导出与预检通过，测试端口已释放。该次模拟覆盖服务和文件交付，原生窗口沿用11月13日记录。

## 2. 剩余窗口检查，一批约5–8分钟

下一批仅补尚未覆盖的真实流程，使用同一隔离资料与合成音频，重新提前安排独占输入；不重复已经有效的双缩放基本启动/播放/正常退出证据。

1. 重复导入已测文件夹，核对去重和本地搜索；检查播放暂停及拖动进度，不能仅凭开始播放推定这些操作通过。
2. 检查收藏/歌单保存和恢复、搜索/BV/发现等在线入口的禁用解释；源码/服务拒绝证据继续复用，但不冒充本轮逐入口GUI验收。
3. 补150%迷你窗口进入/返回，以及备份导出/预检。未做恢复覆盖、删除或原资料写入；此类操作另按实际范围安排。

11月6日的LRCLIB单曲HTTP查询收到合法JSON但返回0候选，只验证传输；11月13日使用本地合成LRC，没有重复公网查询，也不证明真实歌曲歌词匹配。

基本窗口验收不关闭最终NOTICE/SOURCE/校验和、重启和独立电脑条件。是否制作独立安装器及最终公开附件，仍按实际发布形态验收并由用户最终确认。

## 3. 三个重启会话的最小安排

沿用[启动方案](STARTUP_ACCEPTANCE.md)的时间字段、样本数和失败保留原则，每次约3–5分钟；重启由用户自行安排，可能分多次自然重启完成。先完成上批工具与窗口校验，避免在重启后临时修驱动、混入开发环境。

更新后的私有工具位于 `build/windows-prerelease-20261118/reboot/`：

- `reboot-campaign.json` 绑定新候选BuildId与主JAR哈希，当前只为 `prepared-not-started`；没有记录成功样本。
- `start-after-reboot.ps1` 拒绝准备前的系统会话、同一boot重复尝试或改变候选；首次启动需操作者确认自本次重启后尚未运行该候选。该确认是事实记录，**不代替当次输入接管安排**。
- `native-preview-probe.ps1` 已接入按实际 EXE 检测、可见启动及已存在资料文件识别的修正版。入口已通过语法、候选身份初始化和拒绝未确认首启的预检。真实重启采样为 0/3。
- `write-preview-marker.ps1` 记录真实切页前后与关闭动作时刻；标记包含工具调度开销，不把观察上界称为纯渲染时间。

每次保存启动、窗口、界面可操作、服务/代理、正常退出时间及自有资源释放结果。原样记录失败/未完成；同一会话重试可用于诊断，但不能新增一个重启样本。三个不同真实会话完成后，才把真实记录填入[CSV模板](templates/startup-runs.csv)，用现有 `startup-report.py` 汇总，不补造未观察字段。

## 4. 独立设备可用时的一批操作

一台无开发工具的Windows电脑即可开始，按[朋友试用说明](FRIEND_TRIAL.md)完成15–20分钟核心流程并填[反馈模板](FRIEND_FEEDBACK.md)，不要求先凑齐多人。以最终拟公开形态验收：有安装器就验安装/卸载；只有便携包就如实记为解压运行，保留安装门槛未覆盖。先填实际版本、BuildId、系统和缩放，再记录问题。

不需要发送完整曲库、媒体、Cookie或备份。当前没有自动联系朋友、上传材料或安排后台定时检查；环境未具备时保持明确待验。
