# Windows 测试版的在线来源范围

更新：2026-11-18。[v0.2.2-preview.1](https://github.com/Redemption505/Lumen-Music/releases/tag/v0.2.2-preview.1) 已发布为本地优先的 Windows Pre-release，构建为 `lumen-0.2.2-local-20261106.1`。以下分别说明源码、运行时请求与发行附件的范围。

## 1. 已明确的内容边界

| 对象 | 拟公开源码范围 | 运行时及附件范围 |
| --- | --- | --- |
| 本地音乐、嵌入封面、本地/嵌入歌词 | 保留导入、读取、展示和缓存处理代码，使用合成测试 | 使用者选择自己的文件；公开包和截图不附私人音频、歌词、封面或备份 |
| LRCLIB | 使用官方开放的 v1 API，保留匹配、候选确认及本机缓存代码 | 客户端保留听歌触发的查询和显示，并实现身份标识、节流和退避。发行包不附抓取歌词库；API 开放与歌词文本的再分发分别看待 |
| B站搜索、收藏夹、取流、音轨代理/缓存 | 适配实现与合成 fixture 属于拟审查源码，不包含平台真实响应/会话/内容；公开源码不声称获得平台许可 | 官方协议对自动获取服务/内容/数据有明确书面许可条件，尚未取得本项目用途依据。现有完整功能包继续保留私下候选边界，不能仅靠“游客可播”关闭此项 |
| 网易云补充歌词 | 保留已有接口调用代码和合成 fixture | 两个服务条款入口均未取得可核正文，端点用途未得到可适用依据。本地优先候选实际关闭补充查询；日用 full 保留原行为，未标为已授权 |
| 网络封面与合成歌单封面 | 保留处理代码 | 不随公开包附真实封面缓存或含私人/未核素材的截图；用户运行时获取内容单独遵守实际来源条件 |
| 可选AI | 通用兼容客户端，无内置服务账号、密钥或默认付费承诺 | 默认按现有设置由使用者启用并选择服务；发送范围见[AI说明](AI_INTENT.md)。未选择供应商不扩大成任意服务商均获许可或全程本地 |

上述源码范围不新增与项目 GPL 冲突的附加使用限制；它说明项目发布者实际交付什么、没有取得什么来源证据。媒体或平台内容的许可不能由应用自身 GPL 代替。

## 2. 两条可执行的发布路线

| 路线 | 实际影响与前置 |
| --- | --- |
| 完整在线功能测试版 | 维持现有B站搜索/取流/合集和网易云补充歌词；先补本项目具体用途的适用来源依据。没有依据时保持未发布，不能用改版本名或免责声明代替 |
| 本地优先的首次测试版（已发布） | 保留本地曲库、播放、歌词、收藏歌单、首页、备份、窗口控制及 LRCLIB 查询。B站搜索、取流、在线合集和网易云补充歌词已在界面及服务关闭 |

本轮已选择第二条路线并实施：构建资源 `release.profile=local-first` 决定策略，普通源码构建默认仍为full；服务选择实际local provider、不构造B站或demo provider，GET/HEAD音轨和在线目录入口统一拒绝；网易云补充transport返回合法空候选；LRCLIB保留，现有在线元数据可以整理/备份但不能解析播放，HTTP(S)封面不加载。Java在队列和最终音源加载处只允许file URI，并禁预载及日用更新包应用。不是只隐藏按钮。

公开便携版使用 `LumenMusicPreview.exe`、默认18765/18766端口及 `%LOCALAPPDATA%/Lumen Music Local Preview` 资料目录。CLI 策略、隔离 HTTP、本机双缩放窗口及合成音频已验。AI 设置入口保留，依赖在线发现和电台的调用在公开版不可用。[便携测试版验收](LOCAL_PREVIEW_ACCEPTANCE.md)

## 3. 一手依据与未解决项

- [LRCLIB API文档](https://lrclib.net/docs.txt)：明确面向应用开放匿名访问，注册可选；要求客户端身份、顺序请求/节流和尊重退避头。本文只使用这些接口事实，不推断其服务器软件许可证覆盖所有歌词文本。
- [B站用户使用协议](https://www.bilibili.com/blackboard/protocal/licence.html)：2026-11-06官方搜索索引可核§5.6(3)，直接页面正文抽取为空；没有联系平台、申请授权或代表维护者作任何承诺。
- 网易云[现行入口](https://st.music.163.com/official-terms/service)、[旧入口](https://music.163.com/html/web2/service.html)：本轮仍不可取得可核正文，不以第三方转载填补，也不将其他网易产品条款套用到此接口。

组件许可证和对应源码材料见[第三方材料](PHASE4_RELEASE_MATERIALS.md)，最小验收、候选身份和发布确认见[公开测试版准备](PUBLIC_PRERELEASE_READINESS.md)。来源条件未关闭不阻止独立的本地修复与工程测试，也不等于判断项目已违法。
