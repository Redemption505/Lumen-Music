# 个人首页

首页“我的音乐”沿用现有播放会话、曲库、最近播放和私人电台，不需要先生成推荐才能开始使用。四区首页及布局调整已包含于 v0.2.2。

## 四个入口

| 区域 | 使用方法与行为 |
| --- | --- |
| 继续听 | 显示当前或上次保存的队列、曲目和位置，点击“继续播放”恢复；启动仍保持安静。播放中显示“正在播放”，不会再次点击就暂停。无会话时明确显示空状态 |
| 我的常驻 | 放置最多六个普通或智能歌单。普通歌单进入对应曲目页，智能歌单进入整理窗口并选中对应歌单；打开入口不会开始播放 |
| 今日重逢 | 从真实最近播放优先选择重听的老收藏，再选择本周初遇或最近听过的曲目，显示实际日期与理由。点击“回听这首歌”才开始播放；没有有效历史时提供本地音乐、收藏和日记入口 |
| 想发现一点 | 打开原有私人电台，继续使用熟悉/发现、中立模式和反馈；一句话引导、生成推荐与刷新仍沿用现有实现，只更新候选 |

继续听复用原有 `PlaybackStateStore`，不另建首页播放状态。正常退出保存队列和位置；重启时显示已恢复的会话，明确点击后才加载并播放。启动前保存的队列不包含可恢复的歌单来源名称时，首页显示“当前队列”，不推断歌单归属。与其他收藏入口一致，明确回听遵循已有偏好版本。

“今日重逢”只呈现服务已有的真实记录，不补造旧数据的首次日期；日期按最近播放时区显示。打开日记或歌单、调整首页、生成候选都保持当前播放器和队列。

## 调整首页

点击右上角“调整首页”，选择区域或常驻歌单后用“上移 / 下移”排序。从下方选择普通或智能歌单，点击“置顶”；选中常驻后可移除。四个区域均保留，最多六个常驻，同一歌单不能重复加入。

“保存”成功后应用新布局；“取消”丢弃本次调整。保存失败时窗口保持打开，草稿和错误提示保留，可再次保存。保存期间禁止重复提交；首页读取失败保留已有内容，重新进入首页可重试。

歌单改名保持常驻引用；删除普通或智能歌单会同时移除对应常驻。长名称省略显示并提供完整悬停提示。宽窗口采用双列卡片，窄窗口自动单列，所有区域通过纵向滚动到达，底部播放条保持可用。

## 保存与备份

布局与常驻保存于现有 `library.json` 的版本化 `homePreferences` 字段，随已有 ZIP 数据备份导出、预检和恢复。旧曲库缺少字段时使用默认区域顺序与空常驻；无效偏好或未知版本明确拒绝，详情见[备份格式](BACKUP_FORMAT.md)和[接口契约](API.md)。偏好写入不修改收藏、历史、队列或版本目录的一次撤销快照。

首页会话仍使用原有本机播放状态文件，其队列和进度不因新增首页偏好而进入 ZIP；跨机器恢复备份后仍须重新关联不可访问的本地音频。
