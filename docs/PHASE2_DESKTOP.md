# 第二阶段第四步：完整桌面体验

主界面、沉浸页和迷你窗口共用一个 `PlayerQueue` 与当前 `AudioPlayer`（本地 JavaFX、在线 VLC）。沉浸页、底部播放条、迷你播放器及 Windows 任务栏按钮都调用同一组播放、暂停和切歌操作；曲名、进度、封面、歌词与收藏状态从主播放器更新。

## 使用方式

- 点击底部播放栏的封面、曲目信息或展开按钮进入方形封面与滚动歌词视图，点击“收起”回到首页。进度、上一首、播放暂停、下一首统一使用固定在底部的播放栏；沉浸页保留收藏、加入歌单、手动匹配歌词、校准与全文浏览。歌词列表上下渐隐，并在歌词变化时平滑滚动。
- 左侧设置区的“主题”按钮循环深色、浅色、背景图、动态背景、Lumen 暮光五档；其他四档可自选六种主题色，默认樱粉；Lumen 使用固定暖金色。“背景图”从本机选图，复制到个人数据目录后使用，因此可随数据备份导出。动态背景按当前封面取色，缺少封面时使用所选主题色。主题、主题色和桌宠选择保存在偏好文件中。
- 首页采用莓紫到墨色渐变、封面推荐卡片与统一尺寸的矢量播放图标；播放队列由底部“队列”按钮展开。首页搜索框会跳转至真实搜索页。浅色主题保留相同布局与可读对比度。方形封面居中裁切真实视频封面，无封面或同步歌词时显示明确占位；在 860×600 窗口中自动收起歌词校准行，底部播放栏高度固定。左侧导航将设置折叠收纳，桌宠停靠在左下角。左侧“我的歌单”可展开各歌单并点击进入内容页；收藏、歌单与队列均支持对选中曲目收藏、加入指定歌单或安排下一首，队列可拖动排序。
- 自定义无边框标题栏可拖动窗口、双击标题最大化，也有最小化、最大化和关闭按钮。
- “迷你播放器”打开置顶小窗并收起主窗口，可继续上一首、播放暂停、下一首和收藏；点击“返回主窗口”或关闭小窗会恢复主窗口。
- Windows 任务栏悬停缩略图有上一首、播放暂停、下一首三个按钮。它们从窗口所在进程调用 `ITaskbarList3`，并将 Win32 按钮事件转回 JavaFX 播放操作。其他系统不创建该 Windows 控件。
- 左侧桌宠可选小黑咪、糯米飘、橘子汪。形象由 JavaFX 图形绘制，播放、暂停、切歌、收藏成功等实际事件才触发律动或气泡。

## 实现边界

Windows 缩略图按钮使用用户已批准的 `jna` 与 `jna-platform` 5.13.0。Windows 打包脚本把两个运行时 JAR 放入安装包；桌面主窗口和迷你窗口各自注册按钮并在窗口结束时释放 Win32 图标和消息钩子。主题与桌宠只使用 JavaFX，不需要素材下载。

背景图最多 32 MiB，接受 JavaFX 可解码的 PNG、JPEG 和 WebP；不能解码时界面直接报错，不会切换主题。安装版仍需可用的 Python 3.10+ 解释器才能使用在线搜索及个人曲库；本地播放不依赖服务。当前未对 macOS/Linux 的自定义窗口做实机验收。

## 验收结果

- 开发版实际 JavaFX 窗口验证了五档主题切换、六色入口、选图落盘、标题栏最大化、沉浸页/底部播放条同步暂停、迷你窗口同步恢复播放及关闭后返回主窗口；桌宠形象切换和播放状态反应通过。已生成并检查沉浸页与迷你窗口截图。
- Windows 原生窗口探针验证缩略图三个按钮注册、消息分发、图标状态更新及窗口隐藏再显示。安装版的真实 JavaFX 窗口通过 UI Automation 播放演示曲目；向已安装窗口发送三项 `THBN_CLICKED` 消息后，播放暂停与上下首都改变了同一队列。安装版迷你窗口经 Win32 检查为置顶，其任务栏消息也能暂停播放。关闭迷你窗口恢复主窗口，关闭应用后自管 Python 服务停止。
- 安装程序构建、静默安装和启动通过，安装目录包含 JNA/JNA-platform JAR。此处的原生按钮验收验证了 Windows 消息通道及实际状态变化；鼠标悬停缩略图的像素外观尚未单独截图检查。

详细测试记录见[验证结果](VALIDATION.md)。
