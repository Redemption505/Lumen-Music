# 第二阶段第三步：曲库与歌词

本步完成公开收藏夹导入、三处拖拽排序、ZIP 备份恢复和在线同步歌词。桌面端通过本机 Python 服务保存个人数据；歌词查询整合公开 LRCLIB 与网易云华语歌曲和歌词接口，不需要登录或新增依赖。

## 日常操作

- 本地音乐支持导入文件、递归导入文件夹和拖入文件/文件夹，重复路径只保留一条。列表保存到个人数据目录的 `local-music.xml`，重启后恢复；可搜索歌名、歌手及文件名、按文件夹筛选、刷新标签、打开所在文件夹。批量移除先确认，原音频、收藏和歌单保留。
- 常见 MP3 ID3v2.3/2.4、FLAC、M4A/MP4、WAV/AIFF 和 OGG/Opus 标签中的标题、歌手、封面与歌词会自动读取。封面提取至 `local-artwork`，不改原音频。手动匹配/校准记录优先，其后是同名 LRC、内嵌歌词和在线匹配；纯文本歌词仅浏览全文，有时间戳才同步滚动。旧式 ID3v2.2、压缩/加密帧及 SYLT 的 MPEG 帧时间单位尚未支持，可选择外置 LRC。

- 在“歌单”页点击“导入 B 站公开收藏夹”，粘贴公开收藏夹链接或完整数字 media ID。导入后显示成功、失效跳过和重复跳过的数量，并生成本地歌单。只使用游客可读取的公开内容；私密、无权读取或分页失败时保留原曲库。
- 在“收藏”列表、歌单顺序列表、歌单曲目列表中拖动一项到另一项，可改变相应顺序。排序写入版本化 `library.json`，重启后保留；原有上移/下移按钮仍可用。
- 在“歌单”页选择“导出数据备份”保存 ZIP。“从备份恢复”先预检完整性并展示收藏、歌单、听歌记录及成员列表，确认后才写入并刷新当前曲库与推荐。恢复只替换 ZIP 中包含的数据。格式、大小限制和回滚范围见[备份格式](BACKUP_FORMAT.md)。
- 播放时优先恢复已保存的手动匹配；无记录时先尝试同名本地 LRC，再查询在线同步歌词。严格匹配成功才自动应用。可手动输入曲名搜索、选择候选、加载本地 LRC、以 0.5 秒步长校准时间，以及打开全文。手动选择的在线歌词及偏移量按曲目身份保存，重启后优先恢复。在线歌词请求失败时保留当前歌词。

## 身份与匹配边界

收藏夹按原分页顺序导入视频首页身份，保留 BV 号、分 P 页码和封面等可用元数据；失效、非视频和缺少关键身份的条目跳过，重复 BV 只保留一条。读取全部分页成功后才创建歌单，避免半成品。导入并不证明视频实际音频是原曲。

在线歌词候选必须有可解析的 LRC 时间标记。自动匹配要求曲名、歌手明确吻合，原始时长相差不超过 ±5 秒。B 站标题中明确的“歌手 - 曲名”“《曲名》- 歌手”或“歌手《曲名》”可用来识别身份，支持没有分隔空格及标题前后出现音质说明；上传者不等同于歌手。遇到 Live、翻唱、混剪、合辑等版本标记时不自动套用。同曲同歌手的候选中优先采用歌词内容一致且时长完全匹配的记录；相同时长的歌词冲突且没有足够多数共识时交由用户手动选择。同一录音且正文内容一致的候选优先简体歌词，其次繁体；来源标题和 LRC 元数据不影响正文优先级。简繁识别复用内置常见汉字映射，不转换或改写原始歌词。单一来源或候选失败不丢弃已取得的有效结果。歌词来源为 [LRCLIB](https://lrclib.net/docs) 和网易云公开歌曲/歌词接口；视频元数据与歌词的版权归各自权利人。

## 验收

- 确定性测试覆盖游客收藏夹分页、失效与非视频条目、重复 BV、无权读取和中途失败不写入；实际游客请求读取一个公开收藏夹，返回 28 个可导入条目。公开内容可能随时变化，该数字只代表测试时结果。
- JavaFX 实际窗口启动并显示导入、备份和歌词控件；真实鼠标将两个测试歌单拖动换位，服务端曲库顺序同步更新。收藏和歌单曲目使用同一拖拽处理器，并由各自的排序 API 保存。
- 备份测试覆盖预检、导出恢复、可选听歌记录/AI 设置/背景图、损坏或篡改 ZIP 不覆盖原数据、写入故障回滚；HTTP 集成验证恢复后运行中 Store 重新加载。独立文件的断电级原子性不在本步保证。
- 歌词测试覆盖标题修饰、歌手不符、候选冲突、无同步时间标记和上游异常。实际 LRCLIB 查询 `Shape of You / Ed Sheeran / 233` 返回候选且有自动匹配；`Numb / Linkin Park / 185` 的候选存在标题修饰，未自动套用。

完整接口见[接口契约](API.md)，测试统计与仍有限制见[验证记录](VALIDATION.md)。
