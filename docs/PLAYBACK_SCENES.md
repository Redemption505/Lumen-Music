# 视觉与播放场景

## 日常浏览

保留歌曲列表、行内红心和“…”操作。背景、列表内容与悬浮菜单使用不同层级，深色、浅色、背景图、动态和 Lumen 主题共用稳定的排版。

播放队列从右侧进入，仍可拖动边界调整宽度。缩小窗口时侧栏自动使用居中图标，歌曲标题与来源信息优先保留。

## 沉浸听歌

点击底栏歌曲区域或播放页按钮进入；封面从底栏过渡到沉浸页，收起时返回之前的浏览页面。切换页面不会重新加载歌曲或重建队列。

封面保持 16:10 展示，歌词当前句居中跟随。播放中闲置约五秒后，辅助操作、歌词校准与底栏控件淡出；鼠标移动、按键或暂停后立即显现。控件获得焦点时不会自动隐藏。

沉浸页的时钟图标可直接进入专注陪伴。收起按钮或 Esc 返回原来的浏览页面；在文字输入框中 Esc 不接管输入操作。

## 专注陪伴

侧栏“专注陪伴”、设置中的同名入口、快捷搜索或沉浸页时钟图标进入专注页。使用同一播放器，保留当前曲目、队列、播放位置和音量。

- 专注倒计时可选 25、45、60 分钟，支持开始、暂停、继续和结束；到时显示“专注完成”，不会暂停音乐。
- 睡眠定时可选 15、30、45、60、90 分钟；到时暂停音乐并停止电台自动续播，保留当前位置。取消定时不改变播放，按播放键可继续。
- 上一首、播放/暂停、下一首与进度拖动继续可用；返回或 Esc 回到之前的浏览页面。
- 桌宠保持安静，不自动摆动或发出交互话术；点击可获得简短回应。“不显示”设置继续有效。

离开专注页后已启动的计时器继续运行。改变时长会重置对应计时器；关闭应用会取消计时器，重新打开不会自动开始计时或播放。

## 迷你播放器

从底栏进入圆角迷你窗口，显示封面、曲名、歌手、同步歌词和常用播放控制。长句随播放时钟横向流动，暂停冻结、定位同步更新；没有同步歌词时显示明确提示。

长按空白区域约 0.3 秒后拖动，按钮、进度条和窗口边缘保留各自操作。进度条拖动期间锁定播放进度显示，松开后定位；边缘可以调整大小。返回或关闭迷你窗口会回到主界面，保持当前队列、播放位置和暂停状态。

## 减少动态

在设置中开启“减少动态效果”，会立即停止场景过渡、背景流动、桌宠动作与平滑滚动；歌词仍按当前播放时间直接居中，沉浸控件保持可见。滚动、导航、播放与进度拖动不受影响。

此偏好保存在本机，重启保留。动态主题在此模式下使用静止背景；关闭选项后恢复动态效果。快速连续切换页面或队列会取消旧动画，不留下封面或退出叠层。
