# 精听与练习

点击底栏或沉浸页的“精听与练习”图标打开面板，也可在 Ctrl+K 中搜索该操作。面板与当前播放器共用歌曲、进度和音量，关闭面板后循环及速度继续生效。

## 歌词定位

单击沉浸页或侧边列表中的同步歌词，定位到该句开始的位置，保留当前播放或暂停状态。定位使用已保存的歌曲起点和校准偏移；片段歌曲的位置仍是片段自己的相对时间。

Ctrl/Shift 选择多句及右键菜单不会触发定位。歌曲范围以外的歌词不能跳转。音源尚在加载时请等待时长就绪。

在“最近播放 → 歌词”点击播放图标，可直接播放关联曲目并定位到收藏时保存的位置。定位使用收藏时的位置，之后重新校准歌词不会改写旧收藏。

## A–B 循环

- 在需要的位置点击“标记 A”，继续播放到另一位置点击“标记 B”，开始反复播放这段。
- 也可输入 `分:秒.毫秒` 或 `时:分:秒.毫秒`；按 Enter 或离开输入框应用有效范围。
- B 点至少晚于 A 点 0.5 秒，且不能超出当前曲目；已有片段使用片段相对时间。
- 取消“A–B 循环”保留标记，重新勾选可继续；“清除标记”同时移除起终点。
- 循环优先于列表循环、随机及电台续播；手动定位到循环之外会暂停 A–B 循环并保留标记。
- 切换到其他曲目清空标记；重启应用不恢复临时循环。

“保存为片段歌曲”打开片段编辑器，填好歌曲名和目标收藏或歌单即可保存。它创建新片段，不修改原来的片段；同源音频继续共享缓存。可以在保存前试听。

## 播放速度

可选择 0.75×、1×、1.25×、1.5×。更改速度保留暂停状态，在本次应用运行中切歌继续使用所选速度；重新打开应用恢复 1×。

VLC 使用保持音调的变速滤镜；JavaFX 使用自身的变速能力，音调处理取决于引擎。音源拒绝变速时面板会说明原因。

有效听歌时长按实际时间累计，跳转、暂停及卡顿不增加时长；长歌仍需实际听够 30 秒，短歌和短片段按真正播放过的媒体进度达到 90% 判断。同一播放会话的多轮 A–B 练习只入账一次。
