# 私人电台

私人电台把真实检索结果与本机曲库组织成待播候选。无 AI Key 也能使用；AI 可生成检索意图，不直接生成歌曲资源。电台刷新不打断当前播放。

最近七天的收听用于降低重复；有明确版本演唱者时优先错开演唱者，否则按作者错开，不将 B 站 UP 主当作已知歌手。推荐理由依据实际收藏、歌单或检索，不编造关联。

## 开启

- 首页点击 `私人电台`，可沿用首页的一句话引导。
- 歌曲行 `… → 从此曲开启电台`，或沉浸页的 `电台`，从这首歌出发。
- 歌单顶部 `从歌单开启电台`，以所选歌单为种子。

选择 `熟悉一些` 或 `多发现一些`，填写可选的本次引导，点击 `开启电台`。修改模式、引导或“不影响口味”后，重新开启才应用新的条件；`刷新候选` 沿用当前电台条件。

## 待播与续播

候选可预览、查看选中歌曲的推荐依据、直接播放或移出本次。移出的资源不会在本次电台刷新时补回来。候选不足时显示实际可用数量，不编造资源。

电台开启后，当前曲目保持不变，已有队列后续和手动“下一首播放”优先播放，再消费电台候选。电台期间按队列顺序推进，不绕回已安排列表；单曲循环仍优先生效。未设置自动续播时，已安排歌曲结束后停止，候选保留供手动点播。

关闭电台窗口不停止电台；`停止电台` 关闭后续补充但不切走正在播放的歌。重新从普通列表选择歌曲会退出电台，恢复普通队列模式。候选用尽后按本次条件寻找下一批；没有可用候选或请求失败时停止等待，不无限重试。

## 反馈

歌曲行菜单提供 `暂时听腻了` 和 `少推荐这个版本`。前者七天内暂时排除歌曲（已整理的同歌曲版本一起处理），后者降低当前资源权重，不永久禁止播放。一次手动切过只作为弱信号，不等同于不喜欢。

电台窗口的 `口味反馈` 可查看并恢复已保存的反馈，恢复后下次刷新生效。反馈保存在本机曲库，随现有 ZIP 数据备份恢复。

## 本次不影响口味

勾选后不使用长期口味整理本次候选，按本次种子和引导检索；本次电台播放不计入听歌记录，跳过不保存为长期反馈，菜单反馈仅移出本次候选。进入中立模式之前已经实际听过的部分不追溯删除。

原始听歌记录、本地文件路径与私人备注不发送给 AI。无 Key 或 AI 请求失败时使用本机规则；真实在线候选检索仍需要联网。

当前功能已提供于源码及本机安装版，已发布 v0.1.1 分发包尚未同步更新。启动方式见 [README](../README.md)。
