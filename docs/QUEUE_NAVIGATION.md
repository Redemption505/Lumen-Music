# 队列与导航

## 播放安排

播放队列会标明“手动安排”“歌单后续”和“电台推荐”。电台待播候选另外显示在队列下方，已有安排播放完毕后才会续播推荐。

歌曲行的“…”提供“下一首播放”和“添加到队尾”。连续选择下一首时，最近一次操作排在最前；添加到队尾会放在现有安排末尾、电台推荐之前。多选曲目后操作，按列表中的顺序整批加入。

随机模式按顺序播放待播的手动安排。拖拽未来的队列项后，未来区域按新顺序播放；已播放的历史和当前音频保持不变。单曲循环仍优先，结束循环后才推进队列。

从队列移除正在播放的条目，会接着播放后面可用的曲目；没有可用后继时选择前面的剩余曲目。原来暂停时仍保持暂停，移除全部可用曲目则停止播放和电台续播。队列中同一歌曲出现多次时，移除只针对所选条目。

## 撤销

队列标题旁可清空或撤销操作。插入、拖拽、移除和清空可撤销，恢复原顺序及来源；清空会停止电台续播。若操作后已经切歌、改变播放模式或建立了另一份队列，旧撤销不会覆盖新的安排。

普通歌单可以多选后从“…”整批移除，标题区的“撤销移除”恢复原曲目与顺序。目标歌单发生后续修改或服务重启后，旧撤销不再生效。移出歌单及撤销均不会修改正在播放的队列。

Ctrl+Z 在歌单页优先撤销歌单移除，其他页面撤销队列操作；文字输入框保留自己的文字撤销。

## 返回与查找

歌单之间切换时保留各自选中项和滚动位置。搜索条件也会保留；从沉浸播放页或设置返回时，回到之前浏览的页面。窗口缩放、打开播放队列及切换播放页不会重建播放队列。

侧栏“快捷搜索”或 Ctrl+K 打开本地全局搜索，查找收藏、普通歌单、版本资源、本地歌曲和常用操作。上下键选择，Enter 打开或执行，Esc 关闭；搜索歌曲会播放对应资源，搜索歌单会打开列表。

在输入文字或录制快捷键时，播放快捷键不会触发切歌或播放。已有 Ctrl+F 仍打开 B 站搜索，Ctrl+O 打开本地音频导入。
