# 开发阶段与验收

当前发行版本为 v0.2.2。[第三阶段：拓展与整合](PHASE3_EXPANSION.md)的 3.1–3.12 及 [v0.2.1 体验修复](V021_ACCEPTANCE.md)均已提供。[第四阶段：个性化与移动化](../第四阶段.md) §3.1 统一视觉、§3.2 个人首页及 §3.3 本轮桌面收藏记忆已实现、综合验收并同步本机安装与发行，见[v0.2.2 验收](V022_ACCEPTANCE.md)。纪念卡图片导出按原规划后置，安卓独立日常可用版仍待实施。

以下为早期阶段记录，其中“当前”“尚未实现”等描述仅对应当时的阶段，不代表现行发行版。现行能力见 [README](../README.md)，前期优化说明见 [v0.1.1 基础](PHASE3.md)。

## 基础框架：已完成

交付参考调研、项目说明、Java 桌面、Python 演示曲库、HTTP 契约、启动脚本和集成检查。

验收：中文搜索从 Java 到达 Python 并正确解析；选曲建立独立队列；后续搜索不改动队列；上下首循环切换。

## 第 1–2 步：音频引擎与界面接入，已完成

已采用 JavaFX Media，完成本地文件导入和真实播放控制。Windows 本机验证了 MP3、AAC/MP4、WAV 与一个直接 HTTP MP3 示例。演示曲目现在由程序生成 8 秒音频，能在搜索队列中播放，并用实际 JavaFX 窗口验证上下首切换。

旧 Java Sound 仅保留为 PCM 设备诊断。证据见 [音频引擎实验](AUDIO_ENGINE_SPIKE.md)。

界面已提供可拖动进度，演示音频的实际拖动和上下首切换已通过窗口验收。机器无法替代人耳听音验收。

## 第 3 步：B 站真实搜索，已完成当前范围

已实现真实视频搜索、BV 号与分 P 身份字段、空结果及上游失败区分。Java → Python → B 站的真实搜索链路已通过；演示数据源保留用于离线开发。当前没有直接 BV 输入功能。

直接粘贴 BV 号可作为搜索关键词，但专用 BV 输入和多分 P 展开尚未实现。

## 第 4 步：在线取流，已完成可用闭环

Python 按 BV 号与分 P 解析 AAC-LC 音轨，提供本机 HEAD、完整 GET 与单段 Range/206 代理，处理 CDN 备用地址与过期重解析。Java 在后台将所选音轨下载到会话临时文件（上限 256 MB）后交由 JavaFX 播放；真实搜索、播放及拖动进度已在 Windows 本机通过。

直接 HTTP 播放 B 站分段 MP4 时，实测部分音轨报格式不支持，且远距离 seek 可能不生效，因此当前采用完整音轨临时缓存。首次播放需要等待下载；仍需在更多视频、JDK 17 和其他操作系统上验证兼容性。

## 第 5 步：完善播放队列，已完成当前范围

已加入播放结束自动下一首、列表循环/单曲循环/不循环模式。手动切歌仍可绕回队列。快速切歌会取消旧下载并关闭正在读取的响应；加载版本号阻止迟到结果播放，取消后的临时文件不会进入会话缓存。队列快照与搜索结果继续分离。JUnit 验证循环边界和慢速下载取消后的清理与重试；JavaFX 演示窗口验证结束自动切换及连续快速切歌。

## 第 6 步：个人曲库，已完成当前范围

已实现收藏、歌单增删改、曲目去重与手动排序；Python 将版本化 JSON 原子写入磁盘，并保存上一次有效状态的 `.bak`。损坏文件、未知版本、运行期间外部修改均报错并保留原件。JavaFX 可操作收藏和歌单，播放保存的本地或 B 站曲目。自动测试覆盖重启恢复、重复收藏、排序、写入失败和权限拒绝；真实测试用周杰伦《晴天》《青花瓷》相关视频完成搜索、AAC 音轨检查、收藏歌单、重启恢复及窗口播放拖动。播放记录暂未加入当前范围。

## 第 7 步：体验与分发，已完成当前范围

已加入搜索结果封面、本地 LRC 歌词及手动选择、深浅主题持久化、键盘操作和音量控制。统一启动器可按需启动 Python 服务，复用同模式健康服务，正常退出时只关闭自己创建的子进程。Windows `jpackage` 已产出并启动便携应用目录，包含 Java 运行时、JavaFX 和 Python 服务源码；目标电脑仍需 Python 3.10+。WiX 3.14.1 已用于构建 EXE 安装程序，并完成安装、启动、卸载验收。推荐、桌宠等扩展排在核心播放稳定之后。
