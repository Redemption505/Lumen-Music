# 合集批量整理

在歌曲行的 `... → 合集批量整理` 打开；沉浸页也提供“合集整理”入口。整理对象是该曲目的原音源，多 P 使用当前这一 P；从已有片段打开时仍以原音源时间填写。

v0.2.2 修复构建 `lumen-0.2.2-20261007.2` 已修复片段进度前进但 VLC 实际音量为零的问题。已有片段直接沿用，无需重新切片或重建歌单。

## 曲目表

粘贴后点击“生成候选”，例如：

```text
0:00 第一首
3:20 第二首
7:05 - 11:42 第三首
```

支持 `分:秒`、`时:分:秒` 和毫秒小数、方括号时间、常见列表编号及明确的起止范围。一次最多 200 条，不使用 AI 推测歌名或边界。

省略终点时，仅从紧邻的有效起点推断；不跨过坏行。末项只有原音源时长已知才补到源尾，否则必须手填。候选按原顺序显示，逆序、重复、重叠、无歌名和越界都须修正或取消保存该行。

## 检查与保存

选中候选后可修改歌名、歌手、起点和终点，修改即时验证。初次生成的终点是可编辑草稿；调整另一行的起点不会悄悄覆盖已经填写的终点，应一并核对。

“试听”播放该候选的实际片段。播完、点击“结束试听”或关闭窗口会恢复首次试听前的队列、位置和播放状态；若期间另选了歌曲，不覆盖新播放。试听不计入听歌记录。

勾选要保存的片段，选择“我的收藏”或“新建歌单”，确认后一次保存全部有效条目。失败时保留草稿，可以重试；同一次歌单提交不会重复建立歌单。收藏中的同源、同起止范围会跳过并保留原有身份，结果显示实际保存和重复数量。

保存不改动当前播放队列。各片段继续复用完整源音频缓存，支持相对进度、歌词校准、循环、重启及 ZIP 备份恢复。当前不自动读取视频简介或章节，也不裁剪输出音频文件。
