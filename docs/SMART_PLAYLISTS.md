# 智能歌单与曲库整理

“整理曲库”顶部提供完整的智能歌单、标签、文件夹和重复候选四项导航；窄窗口自动换行，不截断按钮文字。删除智能歌单或文件夹、覆盖或移除标签时先展示对象和影响数量，默认取消。删除文件夹只移除分类，保留歌单及歌曲。

从“我的歌单 → 智能歌单与整理”进入，也可从收藏页打开。曲库中单首歌曲的菜单提供“编辑标签”。

## 规则歌单

智能歌单保存筛选规则，曲目来自收藏、普通歌单和已整理的歌曲版本。同一资源只出现一次，不会自行搜索或添加外部歌曲。

规则同时满足才会入选：

| 规则 | 含义 |
| --- | --- |
| 仅收藏、收藏超过指定天数 | 新收藏开始记录真实日期；旧收藏缺少日期时不参与收藏年龄筛选 |
| 最近听过、近期未听 | 使用达到有效收听门槛的本机记录；近期未听要求存在较早的收听记录 |
| 本机暂无记录 | 没有本机有效收听记录，不等于从未听过 |
| 已缓存、未缓存 | 根据本机完整音频缓存判断；同源片段共享缓存状态，本地原文件不等于音频缓存 |
| 时长范围 | 单位为秒；片段使用片段时长，未知时长不参与上下界筛选 |
| 手动标签 | 必须具有列出的全部标签；标签文字精确匹配 |

选择保存的规则歌单后可修改规则、查看最新结果或另存为普通歌单。普通歌单保存当次结果，后续规则变化不会修改这份副本。

整理窗口打开时每 30 秒刷新曲库信息，修改筛选条件会自动更新预览。使用“新建”建立另一份规则，不会覆盖当前选中的智能歌单。

点击播放时，当前结果作为独立队列快照，保留筛选出的具体版本或片段。浏览、刷新规则或修改标签不打断当前音频，也不重建已经开始播放的队列。

## 标签与文件夹

标签可多选曲目后批量添加、移除或替换。建议标签只根据已有标题和版本信息提示，采用前可修改，采用后也能移除；不会自动写入曲目。

文件夹用于归类普通和智能歌单。移出文件夹或删除文件夹不会删除其中的歌单或歌曲。

重复候选基于已有标题提示可能相关的资源，可进入歌曲版本管理检查、合并或拆分。不同演唱者的资源不会自动合并，版本整理沿用现有撤销功能。

## 数据保存

规则、标签、文件夹与新收藏日期保存在本机曲库，随已有 ZIP 数据备份导出和恢复。缓存状态在查看时读取，不会把某台电脑的缓存状态写入规则文件。原有曲库文件可直接读取，缺失日期不会补成导入或升级日期。
