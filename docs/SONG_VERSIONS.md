# 歌曲版本管理

歌曲保存个人名称和备注；版本保存录音室、现场、翻唱等说明与演唱者；播放资源仍是原来的 BV/P、本地文件或片段。整理版本不裁剪音频，也不修改源文件。

## 入口

歌曲行的 `... → 歌曲版本`，或沉浸页的 `版本`，打开当前歌曲的版本窗口。`我的收藏` 顶部的 `版本管理` 可访问已整理的歌曲；窗口里的“其他歌曲”可切换查看其他分组。

## 整理

1. 首次打开资源时，填写歌曲名称、个人备注、版本说明和演唱者，点击 `保存歌曲` 建立歌曲。
2. 从资源候选中选择另一条真实资源，填写其版本说明和演唱者，点击 `加入版本` 并确认。也可输入歌名，点击 `搜索资源` 查找 B 站结果；浏览和搜索不改变播放队列。
3. 选择版本后，`保存版本信息` 修改版本说明与演唱者，`设为偏好` 指定日常播放时采用的资源。
4. `播放此版本` 明确播放所选版本，不改变偏好。`独立收藏` 保留该版本的资源条目；歌曲行的 `播放此资源` 同样不经过偏好替换。
5. `拆分版本` 让资源独立出来，原有收藏和歌单条目保留。将已有歌曲选为目标后，`归入所选歌曲` 可合并分组；保留目标歌曲名称与偏好，合并两边备注和版本。

“可能相关”是本机按歌名、书名号及常见版本标记产生的提示，不是同一录音的判定。不同演唱者不会自动合并；所有归入、合并和替换都需要确认。

自 v0.2.2 起，版本列表将现有偏好置于“我常听的版本（偏好）”，其余资源列在“其他版本”，各组保留原有相对顺序。版本说明使用实际保存的个人标注，现场、翻唱等标签不从标题猜测；未标注时显示“未标注版本”。资源实际为保存片段时追加“片段”，并显示资源标题和来源。偏好来自手动设置，不根据播放次数自动改写；明确“播放此版本”仍使用所选资源。

## 更换资源

播放失败提示中的 `更换资源` 会打开版本窗口。首次使用时先建立歌曲，再选择要替换的版本与新资源，点击 `替换所选资源` 并确认。

替换保留歌曲名称、备注、版本说明及收藏和歌单中的原位置。如果新资源已在同一列表中，会去重并保留被替换条目的位置。歌词校准、时长与缓存使用新资源身份，不沿用旧音源的设置。

编辑不打断当前音频。当前正在播放的曲目保持原快照；队列中尚未播放的被替换资源会更新。再次从曲库选择歌曲时采用新的资源与偏好。

## 保存与撤销

歌曲、版本、偏好和备注保存在本机曲库中，重启后保留，随“设置 → 数据与隐私”中的 ZIP 备份导出和恢复。旧收藏、歌单和片段仍可读取。

`撤销上次整理` 仅恢复最近一次版本操作，包括资源替换影响的收藏和歌单。其后若又修改收藏或歌单，该次撤销失效，不覆盖后续操作。这里的拆分和替换不会删除本地音频文件。
