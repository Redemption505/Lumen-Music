## 当前行为

| 反馈 | 本次结果 |
| --- | --- |
| 常见华语歌曲搜不到歌词 | 在 LRCLIB 基础上补充网易云公开歌词搜索；识别歌手与书名号曲名、无空格分隔和宣传前缀。一个来源或候选失败不会丢弃其他有效结果，无需账号或新增依赖 |
| 缺少删除确认 | 普通/智能歌单、片段、文件夹、批量取消收藏、清理失效条目、备注、保存歌词和批量清除统一显示对象与数量；标签覆盖/移除、版本替换、备份恢复、缓存清空及已有 API 密钥替换也确认。默认焦点为取消，关闭或 Esc 均取消 |
| 侧栏及名称 | 图标使用相同宽度容器，文字起点对齐；界面统一称“最近播放”，使用独立历史图标；旧数据与接口保留原格式 |
| 整理曲库按钮截断 | 四个导航按钮按可用宽度换行，480px 窄窗口和两档缩放保持完整文字与可操作性 |
| 悬浮提示闪烁及重叠 | 复用提示实例，稳定显示时序；透明 Scene 和外层容器、单层背景及清晰文字，移除会进入鼠标区域的阴影 |
| 自动匹配及简体优先 | 标题能明确确认歌手与曲名、原始时长差不超过 ±5 秒时自动选择。同一录音的实际歌词正文优先简体；繁体曲名不代表歌词也是繁体。Live、翻唱、混剪、身份不明或版本冲突保留手动选择，不覆盖已有手动歌词 |
| 桌宠默认及歌词 | 新偏好默认开启沉浸时移到桌面，保留用户已保存的开关选择。匹配播放时显示当前歌词，使用与沉浸页相同字体、16px 字号；跟随桌宠，暂停/无歌词/隐藏/退出及时收起。歌词最多两行，事件提示仍保持紧凑宽度 |
| 迷你播放器 | 真透明圆角窗口，三主题下可用；显示曲名、歌手和滚动歌词，暂停时停止滚动。空白处长按约 300ms 后移动，按钮、进度条和窗口边缘分别处理；进度拖动/键盘定位与主播放器同步，关闭迷你窗返回主界面并保持队列与播放位置 |

单曲收藏心形开关和移出普通歌单属于可直接恢复的日常操作，保留快捷交互；删除歌单不会删除音频文件。
