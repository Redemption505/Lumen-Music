# v0.2.2 安装、启动与本地音乐验收

本轮修复构建为 `lumen-0.2.2-20261007.4`，版本号保持 `0.2.2`。

## 使用变化

安装向导使用中文路径输入和 Windows 标准文件夹选择窗口。升级默认沿用已登记的安装目录。安装文件夹与开始菜单均提供“卸载 Lumen Music”快捷方式；卸载使用系统缓存，删除下载的安装包后仍可使用。

启动时先显示播放器，再在后台启动服务及初始化音频。服务失败时显示重试入口，本地音乐界面仍可使用。关闭过程中会释放仍在初始化的音频资源，避免后台进程遗留。

本地音乐支持文件导入、递归文件夹导入及拖放，重叠目录和重复文件会去重。可搜索歌名、歌手及文件名，按所在文件夹筛选、定位原文件、重新读取标签或从本地列表移除。移除需要确认，仅移除列表引用，保留原音频、收藏与歌单。

导入后自动读取常见音频中的歌名、歌手、内嵌封面和歌词。歌词优先采用已保存的手动匹配及校准，其次是同名 LRC，再是内嵌歌词。带时间戳的歌词同步显示；纯文本歌词提供全文阅读，不推测逐句时间。窄窗口中的歌词可滚动查看，匹配控件收起后仍可展开使用。

本地目录保存到 `%LOCALAPPDATA%\Lumen Music\local-music.xml`，重启后恢复列表及已读取的资源。音频文件不被复制或改写。元数据缓存位于同一数据目录的 `local-artwork` 和 `local-lyrics` 中。原有收藏、播放记录、设置及手动歌词继续使用原数据目录。

## 已知边界

朋友的首次启动闪退未取得崩溃日志，不能确认其具体原因。此次修复覆盖已确认的同步启动阻塞及关闭时资源交接问题；启动失败、重试及界面响应由运行测试验收。

标准文件夹选择动作及安装向导连接关系有安装包检查，真实首装、升级和缓存卸载有独立生命周期测试；本轮未通过鼠标实际操作安装向导的文件夹选择窗口。

元数据读取覆盖 MP3 ID3v2.3/2.4、FLAC、M4A/MP4、WAV、AIFF、Ogg/Opus 的常见标签。旧 ID3v2.2、加密或压缩标签及使用 MPEG 帧单位的 SYLT 歌词暂不支持；没有时间戳的歌词不会自动变为同步歌词。
