# Windows 使用指南

适用于 Windows 10/11 x64 的 Lumen Music 安装版。程序内置 Java、Python 和 VLC，无需开发工具、账号登录或 API Key 即可听本地音乐。在线搜索、在线歌词与发现需要联网，AI 设置可选。

当前安装候选是 v0.2.2 / `lumen-0.2.2-20261024.1`，包含第三阶段前端改进及六项回归修复。本机同版本升级及原资料保留通过，首页、歌单、本地音乐、迷你返回焦点与返回、正常退出和自有进程/端口释放均已原生验证；本轮未开始播放。此前 `lumen-0.2.2-20261010.1` 的五次原生运行结果保留原构建范围；系统重启首启、独立电脑及原闪退者复测仍待完成。完整包、增量包及对应源码的身份与旁置校验和按[候选说明](PHASE4_RELEASE_CANDIDATE.md)核对。试用时核对[朋友试用说明](FRIEND_TRIAL.md)中的唯一构建号。

## 安装与确认版本

1. 将完整 Windows 包解压到普通文件夹，运行其中的 `LumenMusic-0.2.2-Setup.exe`。
2. 在“选择安装位置”输入完整路径，或点“浏览…”选择文件夹，再按向导完成安装。首次安装只为当前 Windows 用户安装；升级默认沿用已登记目录。
3. 从桌面或开始菜单打开 Lumen Music。界面出现后仍会在后台准备服务与音频，等待提示完成；服务连接失败时可重试，本地音乐仍有独立入口。
4. 打开“设置 → 版本与反馈”，记录版本与完整构建号。Windows“设置 → 应用”中的版本号不能区分同版本的修复构建，也可能在增量更新后仍是旧版本。

旧安装向导选择目录后报错 `2856` 的重复跳转及路径显示问题已修复，并纳入此前 D 候选；目录选择的原生交互证据及安装器生命周期验证见[候选说明](PHASE4_RELEASE_CANDIDATE.md)。10 月 22 日候选的本机同版本升级通过，独立电脑及原首次启动闪退反馈者仍待复测。

同一电脑重复启动会唤回已有窗口。恢复上次队列时保持暂停，明确点击播放才发声。

## 升级与卸载

升级前在“设置 → 数据与隐私”导出一份数据备份，保留旧包。完整安装器可直接升级，无需先卸载；旧 v0.2.2 升至本轮候选也使用完整安装器升级。相同构建再次运行可能显示维护选项，不能把它当作不同修复构建的升级方法。

v0.2.1 可使用专用 v0.2.1 → v0.2.2 增量 ZIP。在“设置 → 版本与反馈 → 选择本地更新包”选择 ZIP，核对来源版本和目标构建，再确认“更新并重启”。应用使用自己内置的更新工具，不执行 ZIP 自带脚本。也可解压完整更新包，完全退出播放器后运行 `update.cmd`，输入包含 `LumenMusic.exe` 的实际安装目录；自选目录不能直接接受默认路径。

增量更新只替换清单内的程序文件，复用已校验的运行环境，不重建 Windows 安装登记或安装器的卸载入口。需要同步登记或补齐入口时，使用完整安装器升级。更新失败先保留提示、`result.xml` 和 `update-backup-v0.2.1-*` 备份；不要手动覆盖程序文件或删除恢复材料。下次启动可在“版本与反馈”查看结果。细节见[本地更新与诊断](UPDATES_FEEDBACK.md)。

卸载前退出播放器。可打开开始菜单的“Lumen Music → 卸载 Lumen Music”，或安装目录内同名快捷方式，也可用 Windows“设置 → 应用”卸载。完整安装器提供的快捷方式使用 Windows 缓存，删除下载的 Setup.exe 后仍可卸载。卸载移除程序和快捷方式，保留个人曲库、记录及设置；不会删除原音频。更早安装或仅做过增量更新时，入口以原安装登记为准，见[安装与卸载](WINDOWS_INSTALLER.md)。

## 导入文件夹、封面与歌词

打开左侧“本地音乐”，选择“导入文件”或“导入文件夹”；也可把文件、文件夹拖入该页面。文件夹会包含子目录，重复导入和重叠目录会去重。按歌名、歌手或文件名搜索，并使用文件夹筛选找到歌曲，再选择播放。

导入会读取常见内嵌标题、歌手、封面和歌词；列表与读取结果在重启后保留。源文件修改标签后可点“刷新标签”，选择曲目后可点“打开所在文件夹”。“移除所选”需要确认，只移除本地列表引用，原文件、已有收藏和歌单仍保留。音频不会复制到应用目录，移动或删除原文件后需要从实际位置重新导入。

歌词顺序为已保存的手动匹配及校准 → 与音频同名、同目录的 `.lrc` → 内嵌歌词。可以在歌词的“匹配与校准”入口选择“选择 LRC 歌词”，或在沉浸页使用“手动匹配歌词”。带时间戳的歌词可同步跟随与定位；纯文本只阅读全文，不会自动生成逐句时间。没有封面或歌词不影响听歌。常见标签支持及限制见[本地音乐验收](V022_INSTALL_LOCAL_ACCEPTANCE.md)。

普通歌单页可选择本地歌单封面和填写简短说明；未设置封面时使用已有曲目封面的组合。歌曲封面和歌单封面是不同内容。

## 收藏、恢复与备份

歌曲红心用于收藏；在左侧“我的歌单”建立普通歌单并加入曲目。退出后重新打开，核对收藏和歌单；首页“继续听”可恢复已保存队列，仍需点击播放。

在“设置 → 数据与隐私 → 导出数据备份”选择独立的 ZIP 保存位置，等待“备份已保存”。恢复前先导出当前资料，再点“从备份恢复”选择 ZIP，阅读完整性检查后的收藏、歌单、记录数与文件列表，确认替换。恢复会替换备份中包含的当前数据，不是自动合并；检查失败时先保留原备份和现有资料，不要改 ZIP 内容试图跳过检查。

备份包含收藏、歌单及封面说明、首页布局、备注与歌词收藏、听歌记录，以及实际存在的非密钥 AI 设置和背景图。**它不包含原音频、音频缓存、本地音乐导入列表、本机播放会话、独立 API Key、桌面外观/快捷键设置或手动歌词匹配缓存。** 换电脑时需另行保存原音频并重新导入，按需要重新配置这些本机内容；不能把 ZIP 当作整个个人目录的完整副本。格式见[数据备份](BACKUP_FORMAT.md)。

备份包含私人内容，仅自行保存和恢复。AI 地址的查询参数也可能是私人信息；反馈普通问题使用诊断包，不发送个人备份。

## 启动失败与反馈

应用能打开时，先记录“设置 → 版本与反馈”的完整构建号、错误提示和复现步骤；服务失败可使用界面重试。可点“导出诊断信息”保存诊断 ZIP，查看后再决定是否分享。它仅含 `diagnostics.txt`：版本、系统类型/架构、Java、播放状态/相关开关，以及最近最多 20 条错误的 UTC 时间与固定代码，不读取原始服务日志、曲库或密钥。

应用打不开时，不需要安装开发工具：

1. 记录打开时间、从哪个快捷方式启动、是否出现窗口/提示、何时退出，以及 Windows 版本。截图或录屏避开私人内容。
2. 确认收到的包：完整包解压后，打开或单独解压其中的 `SOURCE.zip`，查看其根目录 `BUILD-INFO.txt` 的 `Version=` 和 `BuildId=` 两行；无需运行源码。增量包还可查看 `manifest.xml` 的 `fromVersion`、`toVersion`、`buildId`。这只能证明收到的包身份，不能证明升级成功；无法启动时把“已安装构建”记为待确认。
3. 在文件资源管理器地址栏输入 `%LOCALAPPDATA%\Lumen Music`。默认可检查 `diagnostics.xml` 和 `service.log` 是否存在、修改时间是否对应失败时间；若没有生成，直接报告“文件未生成”，不要创建空文件，也不要清空个人目录来排查。
4. `diagnostics.xml` 是固定错误码记录，可先只复制本次时间附近的时间和代码。`service.log` 是内置 Python 服务与音频代理追加的原始输出，**不等于白名单诊断 ZIP**；先在本机查看，再只摘录必要错误行，去掉账号、个人路径、URL 查询参数、令牌等信息。无需默认发送完整原始日志。

若启动方式曾自定义 `LUMEN_LIBRARY_PATH`，`diagnostics.xml` 随曲库文件所在目录；启动器的 `service.log` 仍在默认 `%LOCALAPPDATA%\Lumen Music`。自定义 `LUMEN_PREFERENCES_PATH` 只改变偏好文件位置。普通安装无需设置这些变量。默认外观偏好在 `%APPDATA%\Lumen Music`；这两个个人目录可能包含密钥和私人内容，不要整目录发送或作为普通问题附件。

这些文件可能在启动很早失败、未启动自有服务、没有记录错误或写入失败时不存在。没有日志不能证明没有问题。仍无法定位时，先提交[反馈模板](FRIEND_FEEDBACK.md)的最小信息，再按具体现象决定进一步取证，不猜测原闪退原因。
