Lumen Music 0.1.0 | Windows x64 正式版

安装与启动
1. 将整个发布 ZIP 解压到普通文件夹，不要直接在压缩包内运行程序。
2. 在解压后的文件夹中双击 LumenMusic-0.1.0-Setup.exe，按提示完成当前用户安装。
3. 从开始菜单中的 Lumen Music 启动。适用于 Windows 10/11 x64；无需另外安装 Java、Python 或 VLC。

开始使用
点击“导入本地音频”可播放 MP3、AAC/MP4 或 WAV；搜索框可输入关键词、BV 号或 B 站视频链接。双击结果或加入队列后播放，支持多分 P、收藏、歌单、同步歌词、播放模式、迷你播放器和推荐。导入 B 站公开收藏夹不要求登录 B 站账号。

本地文件播放可离线使用。B 站搜索、在线音频、在线歌词、公开收藏夹和在线推荐需要访问相应网络资源，内容能否播放取决于资源和网络状态。AI 推荐是可选功能；启用时需自行在“设置 → AI 推荐”填写兼容服务的 HTTPS 地址、模型和 API Key。

数据与反馈
“设置 → 数据与隐私”可导出或恢复个人曲库 ZIP 备份。备份不包含 AI API Key，换机后需重新填写；收藏的本地歌曲仍依赖原音频文件，请一并保留或重新导入。个人数据、歌词记录及可选音频缓存位于 %LOCALAPPDATA%\Lumen Music；服务日志为该目录中的 service.log。

遇到问题时，请记录 Windows 版本、操作步骤、界面错误文字，以及相关 BV 号或链接；在线内容还可先确认同一链接能否在浏览器打开。反馈时可附 service.log，但请先检查其中是否有不愿分享的信息。第三方组件信息见 THIRD-PARTY-NOTICES.txt。
