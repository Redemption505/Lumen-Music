Lumen Music 0.1.1 歌词修复 | Windows x64

适用：已经安装原版 0.1.1 的用户。首次安装或仍在 0.1.0 的用户请使用对应完整安装包或 0.1.0 → 0.1.1 更新包。

1. 将整个 ZIP 解压到普通文件夹。
2. 完全退出 Lumen Music。
3. 双击 lyrics-hotfix.cmd，按提示输入原安装目录（包含 LumenMusic.exe 的文件夹）；默认安装位置可直接按回车。
4. 出现“歌词修复完成”后，照常从桌面或开始菜单启动。

多 P 视频会按分 P 独立计时。单个长视频中后续歌曲的歌词，可在手动匹配时填写该曲在视频中的起点；也可播放到当前歌词句，选择“对齐选中句”。设置的起点会缓存保存。

修复程序只替换 app/lumen-desktop-0.1.1.jar，原文件备份在安装目录的 update-backup-v0.1.1-lyrics-* 文件夹中。它会核对安装版本、启动配置及新旧 JAR 的 SHA-256，已修复时可安全重复运行；其他文件版本会被拒绝。个人曲库、设置、歌词选择和缓存不会被修改。

本包附有与修复对应的 SOURCE.zip、LICENSE.txt 和 THIRD-PARTY-NOTICES.txt。
