Lumen Music 0.1.1 | Windows x64

安装与更新
首次安装：解压完整发行 ZIP，双击 LumenMusic-0.1.1-Setup.exe，按提示完成安装。
已有 0.1.0：推荐下载较小的 0.1.0-to-0.1.1-Update ZIP，解压后双击 update.cmd。先退出 Lumen Music，按提示输入原安装目录（含 LumenMusic.exe 的文件夹）。更新不需要重新下载 Java、Python 和 VLC，也不会清除个人曲库、设置或缓存。请勿从 ZIP 内直接运行。
已装原版 0.1.1：下载 0.1.1-Lyrics-Hotfix ZIP，解压后退出播放器并双击 lyrics-hotfix.cmd。它只修复程序 JAR，版本号仍为 0.1.1，原有曲库、设置和缓存不变。
也可以运行 0.1.1 完整安装程序升级旧版，无需先卸载。Windows 10/11 x64；无需单独安装 Java、Python 或 VLC。

使用
点击“批量导入本地音频”可一次选择多首 MP3、AAC/MP4 或 WAV；搜索框可输入关键词、BV 号或 B 站视频链接。双击结果或使用歌曲行的红心、... 菜单执行逐曲操作，支持收藏、歌单、同步歌词、播放模式、迷你播放器和推荐。在线内容需要网络，AI 推荐在独立“设置”页面中按需配置。

0.1.1 新增桌宠持续动画，可切换桌面悬浮、拖动定位，双击还原；设置改为独立页面。深色菜单显示和歌词时间校准也得到修复。

数据与许可
个人数据位于 %LOCALAPPDATA%\Lumen Music。可在“设置 → 数据与隐私”导出或恢复曲库备份；备份不包含 AI API Key。Lumen Music 采用 GNU GPL v3；LICENSE.txt 为许可证全文，SOURCE.zip 包含对应版本源码。第三方组件说明见 THIRD-PARTY-NOTICES.txt。
