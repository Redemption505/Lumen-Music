Lumen Music 0.1.0 → 0.1.1 离线增量更新

1. 将整个更新 ZIP 解压到普通文件夹。
2. 完全退出 Lumen Music。
3. 双击 update.cmd；按提示输入原安装目录，即包含 LumenMusic.exe 的文件夹。若使用默认安装位置，可直接按回车。
4. 显示“更新完成”后从原有开始菜单或桌面快捷方式启动。

更新器会校验旧版及更新文件，拒绝错误目录、损坏文件和运行中的程序。它只替换安装目录的 LumenMusic.exe 及 app 中清单列出的文件，并将旧文件留在安装目录的 update-backup-v0.1.0-* 文件夹中。曲库、设置和缓存不受影响。更新无需联网、管理员权限或另装工具。

本包同时附有 LICENSE.txt、SOURCE.zip 和 THIRD-PARTY-NOTICES.txt，对应本次 0.1.1 更新。

增量更新会替换程序启动器，但 Windows“已安装的应用”中的安装记录可能仍显示 0.1.0；这是原安装程序的登记信息。需要同步更新该记录时，可运行完整 0.1.1 安装程序升级，无需先卸载。

如遇问题，请保留更新窗口中的错误信息与备份文件夹。
