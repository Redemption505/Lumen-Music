Lumen Music v0.2.0 · Windows 10/11 x64

首次安装：解压本包，运行 LumenMusic-0.2.0-Setup.exe，安装后从桌面或开始菜单打开。
已安装 v0.1.1：使用较小的 v0.1.1 → v0.2.0 更新包；也可运行完整安装程序升级，无需先卸载。

本版包含整个第三阶段：片段歌曲、合集批量整理、歌曲版本、私人电台、智能歌单、明确的队列安排、浏览/沉浸/专注场景、音乐日记与桌宠、歌词定位与 A–B 练习、变速和下一曲准备。短淡入淡出与本地音频缓存可在设置中开启。

程序内置 Java、Python、JavaFX 和 VLC，无需开发环境、B 站登录或 API Key。本地音频可离线播放；B 站音乐、在线歌词和发现需要联网，AI 配置是可选项。

收藏、歌单、记录、歌词、设置和缓存保存在本机。设置 → 数据与隐私可导出/恢复个人备份；本地音频文件本身不随备份移动。设置 → 版本与反馈显示本版信息，可选择后续本地更新包或导出诊断 ZIP。诊断只包含版本、引擎状态、功能开关和最近错误代码，不含密钥、私人内容、曲目/听歌记录、原始日志或本地文件路径。

本包按 GNU GPL v3 分发，包含 LICENSE.txt、对应 SOURCE.zip、第三方声明及 SHA256SUMS.txt。个人数据不会自动上传；更新使用本地更新包，暂无在线自动更新。
