Lumen Music v0.1.1 → v0.2.0 本地更新

适用于 v0.1.1 原版、歌词修复版及本机第三阶段构建，保留原有个人数据。更新包复用绝大多数运行环境，只附上需要统一的 Java 镜像文件；无需重新安装 Python 或 VLC。

1. 解压整个更新包到普通文件夹。
2. 完全退出 Lumen Music。
3. 双击 update.cmd，输入包含 LumenMusic.exe 的原安装目录。默认安装位置可直接按回车，输入 Q 可取消。
4. 显示更新完成后，从原有快捷方式打开播放器。设置 → 版本与反馈应显示 v0.2.0。

更新器检查来源版本、保留运行环境、全部更新文件的大小和 SHA-256，错误包不会改动程序。更新只覆盖清单中的程序文件，原文件备份在安装目录 update-backup-v0.1.1-* 下。写入失败时尝试恢复并核对原文件；请保留失败信息、result.xml 和备份目录，不要手动删除这些内容。

本包附有对应 SOURCE.zip、LICENSE.txt 和 THIRD-PARTY-NOTICES.txt。更新无需联网、管理员权限或额外安装工具。

程序内的“选择本地更新包”用于后续版本。旧版 v0.1.1 没有这个入口，本次使用上述 update.cmd 即可。增量更新后 Windows“已安装的应用”的登记版本可能仍显示 v0.1.1；实际应用版本以设置和启动器为准。运行完整 v0.2.0 安装程序可同步安装登记。
