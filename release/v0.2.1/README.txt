Lumen Music v0.2.1 · Windows 10/11 x64

首次安装：解压本包，运行 LumenMusic-0.2.1-Setup.exe，安装后从桌面或开始菜单打开。
已安装 v0.2.0：可使用 v0.2.0 → v0.2.1 本地更新包，也可运行完整安装程序升级，无需先卸载。

本版改善歌词、队列、导航和批量整理的使用体验。当前播放的长歌词随进度横向流动；队列清空使用垃圾桶图标。沉浸场景保留“在 B 站打开、收藏、加入歌单、手动匹配歌词”四个主要操作，其余操作收进更多菜单；悬停提示持续显示。音乐日记使用心形与更多入口。

侧栏导航固定，歌单区域独立滚动，文字显示更完整。收藏页区分歌曲版本和智能整理图标；主曲目页提供批量选择、收藏、加入歌单、稍后播放和移除入口。重新打开歌单时，失败封面会自动重试，已匹配的歌词会恢复显示。

开启响度归一化后，前 20 秒音频测量得到的增益平滑应用，手动音量调整也更平滑。普通窗口使用圆角，侧栏宽度改变带有过渡；折叠侧栏时桌宠转移到桌面右下角，展开后回到侧栏。

程序内置 Java、Python、JavaFX 和 VLC，无需开发环境、B 站登录或 API Key。本地音频可离线播放；B 站音乐、在线歌词和发现需要联网，AI 配置是可选项。

收藏、歌单、记录、歌词、设置和缓存保存在本机。设置 → 数据与隐私可导出或恢复个人备份；本地音频文件本身不随备份移动。设置 → 版本与反馈显示实际应用版本，可选择本地更新包或导出诊断 ZIP。
