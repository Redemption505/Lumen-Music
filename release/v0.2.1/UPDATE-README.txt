Lumen Music v0.2.0 → v0.2.1 本地更新

适用于 v0.2.0，保留原有个人数据。更新包核对并复用原有 Java、Python、VLC 及依赖文件，附带目标版本的 Java 镜像文件。本次改善长歌词流动、沉浸页与音乐日记操作、侧栏与歌单滚动、批量整理、封面和歌词恢复、音量平滑及窗口与桌宠过渡。

1. 解压整个更新包到普通文件夹。
2. 在程序的设置 → 版本与反馈中选择本地更新包，按提示退出并更新。也可完全退出 Lumen Music 后双击 update.cmd，输入包含 LumenMusic.exe 的原安装目录；默认安装位置可按回车，输入 Q 可取消。
3. 更新完成后，从原有快捷方式打开播放器。设置 → 版本与反馈应显示 v0.2.1。

更新器检查来源版本、保留运行环境、全部更新文件的大小和 SHA-256；不符合清单的包会在写入前拒绝。更新只覆盖清单中的程序文件，原文件备份在安装目录 update-backup-v0.2.0-* 下。写入失败时尝试恢复并核对原文件；请保留失败信息、result.xml 和备份目录。

本包附有对应 SOURCE.zip、LICENSE.txt 和 THIRD-PARTY-NOTICES.txt。更新无需联网、管理员权限或额外安装工具。

增量更新后 Windows“已安装的应用”的登记版本可能仍显示 v0.2.0；实际应用版本以设置和启动器为准。运行完整 v0.2.1 安装程序可同步安装登记。
