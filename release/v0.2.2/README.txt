Lumen Music v0.2.2 · Windows 10/11 x64 · 私下内测候选

首次安装：解压本包，运行 LumenMusic-0.2.2-Setup.exe，安装后从桌面或开始菜单打开。
已安装 v0.2.1：可使用 v0.2.1 → v0.2.2 本地更新包，也可直接运行完整安装程序升级，无需先卸载。
已安装早期 v0.2.2：本包构建号为 {{BUILD_ID}}，可直接运行完整安装器升级，沿用原目录并保留个人资料。
安装向导支持输入完整路径与 Windows 标准文件夹选择。安装目录和开始菜单均有“卸载 Lumen Music”，删除下载的 Setup.exe 后仍可卸载；卸载保留个人曲库、记录和设置。

本版将播放器整理成个人音乐空间。五种主题使用一致的颜色、完整封面与操作状态。“我的音乐”首页可继续上次队列、打开常驻普通/智能歌单、回听最近播放的音乐，或进入私人电台；启动保持安静，明确点击才播放。首页布局可调整并随数据备份保存。

普通歌单可设置本地封面和简短说明；未设置时自动组合已有曲目封面。歌曲版本页明确展示“我常听的版本”与其他版本。最近播放按真实日期浏览私人备注和收藏歌词，未知日期不补造；歌词可从保存位置回听，保存失败保留草稿并可重试。
本次完善华语同步歌词来源：明确曲名与歌手、时长相差不超过五秒的常见歌曲可自动匹配，同版本优先简体歌词。删除和清理先展示确认，默认取消；整理曲库导航完整展示，悬浮提示更稳定易读。桌宠沉浸转移默认开启，桌面播放时显示当前歌词；迷你播放器提供透明圆角、同步滚动歌词、长按移动及进度定位。保留平滑滚动、长视频片段音量和退出时桌宠清理修复。

界面显示后在后台准备服务和音频引擎，服务连接失败可以重试。本地音乐支持导入文件/整个文件夹、拖入文件/文件夹、搜索与文件夹筛选、刷新标签和定位原文件。列表重启保留，移除条目不删除音频。自动读取常见内嵌标题、歌手、封面和歌词；带时间戳的歌词同步流动，纯文本歌词可浏览全文，已有手动匹配与校准优先保留。

程序内置 Java、Python、JavaFX 和 VLC，无需开发环境、B 站登录或 API Key。本地音频可离线播放；在线搜索、歌词和发现需要联网，AI 配置是可选项。

收藏、歌单、听歌记录、歌词、设置和缓存保存在本机。设置 → 数据与隐私可导出或恢复 ZIP 备份；自选歌单封面与说明随备份保存，本地音频文件和本机播放会话不随 ZIP 移动。设置 → 版本与反馈显示实际版本，可选择本地更新包或导出诊断 ZIP。

本候选包含第四阶段 B/C 修复：损坏偏好与歌词原件保护、AI 本机请求及配置/密钥写入边界、繁忙退出和拖动回退目标进度保存，以及安装文件夹选择后路径立即刷新。最近播放在服务就绪后加载，连接失败反馈可读且支持重试恢复。独立电脑试用及朋友原首次启动闪退复测仍待验证。音源、歌词、素材与部分二进制组件的再分发材料仍有未决项，见 SOURCE.zip 内 docs/THIRD_PARTY_REVIEW.md；本包不代表已获公开发布许可。
