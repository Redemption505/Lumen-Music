适用于 v0.2.1，保留原有个人资料。新增统一视觉语言、个人首页、歌单封面与说明、偏好版本展示，以及按真实日期回顾的最近播放卡片。更新包复用现有 Python、VLC 和依赖文件，附带目标版本的 Java 镜像文件。
目标构建为 {{BUILD_ID}}，包含华语歌词自动匹配、删除确认、最近播放与整理导航、稳定悬浮提示、桌宠歌词及圆角迷你播放器，并保留平滑滚动、长片段音量和退出修复。此构建还将服务与音频初始化移到界面显示后的后台，提供连接失败重试；支持持久本地文件/递归文件夹导入、拖放、搜索与文件夹筛选、刷新标签、定位原文件，以及常见内嵌封面和歌词。移除本地列表引用不会删除音频。
已经安装早期 v0.2.2 时，使用完整包中的安装器升级至本构建，沿用已登记的安装目录并保留个人资料；本增量包只供 v0.2.1 使用。

本次调整首页卡片间距、紧凑布局与主题细节，将整理入口、播放状态和辅助说明放入标题行，回听操作横向排列，并区分普通与智能常驻歌单。修正首页辅助/常驻按钮与侧栏折叠按钮的配色覆盖、迷你播放器返回按钮缺少键盘焦点边框、歌单操作栏样式未生效三处问题。

1. 解压整个更新包到普通文件夹。
2. 在设置 → 版本与反馈中选择本地更新包，按提示退出并更新；也可完全退出播放器后双击 update.cmd，输入含 LumenMusic.exe 的安装目录。
3. 从原快捷方式启动，设置 → 版本与反馈应显示 v0.2.2 / {{BUILD_ID}}。

更新器先核对来源版本、运行环境、文件大小和 SHA-256，只覆盖清单中的程序文件。原程序备份在安装目录 update-backup-v0.2.1-*；写入失败会尝试恢复并核对原文件，请保留错误信息、result.xml 和备份。

本包附对应 SOURCE.zip、LICENSE.txt、THIRD-PARTY-NOTICES.txt 和校验和。更新无需联网、管理员权限或额外安装工具。增量更新只替换清单中的程序文件，不重建 Windows 安装登记，也不创建或修复安装器提供的卸载入口；登记可能仍显示 v0.2.1。完整 v0.2.2 安装器升级可同步安装登记，并提供安装文件夹和开始菜单中的“卸载 Lumen Music”。
